# SafeBites

SafeBites is a web app that helps users filter and explore allergy-safe food options with a clean, easy-to-use interface.

## 🚀 Getting Started

Follow these steps to run the app locally:

```bash
# Clone the repo (if you haven't already)
git clone https://github.com/your-username/saferbites.git
cd saferbites

# Install core dependencies
npm install

# Install missing packages
npm install react-use react-confetti

# Start the development server
npm start
